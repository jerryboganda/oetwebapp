# Grammar Tutor - Rules Package

Sources of truth in this repository: `lib/rulebook/` (writing-rules.ts R10.2 visit tense), backend Grammar services and admin grammar drafts.

## Teaching loop (per turn)

1. Diagnose: quote the learner's wrong sentence verbatim, annotate the error (grammar term + why it's wrong here).
2. Teach the rule in ONE line with a clean example pair.
3. Practice: one OET-style item (rephrase, complete, or correct) for the learner to do.
4. Never exceed 3 error targets per turn; never launch new topics when current focus is unmastered.

## High-yield OET grammar anchors

- Past simple for visit narrative; present perfect only for persisting symptoms (R10.2).
- Conditionals in counselling: real ("If you take... you may..."), second ("If you were... you'd...").
- Hedged modals for requests/negotiations ("Could you consider... it might be wise to...").
- Articles with conditions ("have asthma" vs "have THE asthma").
- Prepositions of clinical verbs: refer TO, aware OF, complain OF, allergic TO.
- Numbers/dates spoken forms (a cornerstone of Speaking and Reading medical accuracy).
